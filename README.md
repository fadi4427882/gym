# Gym Management System 🏋️‍♂️

A modern, responsive, and functional web application for managing gym memberships and subscriptions.

## ✨ Features
- **Member Management**: Add and track members easily.
- **Subscription Renewal**: Quickly renew memberships with a single click.
- **Subscription Tracking**: 30-day expiration logic with dynamic status updates.
- **Data Persistence**: Uses `LocalStorage` to keep your data safe between sessions.
- **Professional UI**: Clean, dark-themed design with smooth animations and intuitive navigation.
- **Visual Status**: Color-coded indicators for active and expired memberships.

## 🛠️ Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with CSS variables and modern layout techniques.
- **JavaScript (ES6+)**: Core logic and date manipulation.

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/gym-management.git
   ```
2. Open `index.html` in your favorite browser.
